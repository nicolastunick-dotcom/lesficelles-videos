# Actu — Le piège caché dans Optimizely (17/11/2026)

**Titre** : 178 organisations piégées : le chiffre qui compte, on ne l'a pas

**Description (à coller telle quelle : sources et crédits DANS la description)**
Selon le chercheur Scott Helme, un outil de l'entreprise Optimizely, installé sur de grands sites, a distribué du code malveillant à leurs visiteurs. Au moins 178 organisations concernées, dont CNN, la BBC et Zoom, selon la liste reprise par la presse. Combien de visiteurs touchés ? Personne ne peut le dire.
