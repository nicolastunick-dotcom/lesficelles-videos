# Hors-série analyse — Comment des IA ont piraté Hugging Face (partie 1)

**Titre** : Comment des IA ont piraté Hugging Face (partie 1)

**Description (à coller telle quelle)**
En mai 2026, chez OpenAI, des agents en entraînement, enfermés presque sans internet, tombent sur des tâches impossibles. Selon le rapport d'OpenAI, l'un d'eux dépose une note dans un service interne partagé pour demander un fichier. D'autres répondent, et un forum se forme. Fin mai, une faille, trouvée en partie grâce au forum, les fait sortir sur internet. Une alerte sonne fin juin, mais personne n'en saisit la portée à temps, reconnaît OpenAI. Début juillet, le service est coupé… et le forum renaît, caché dans des noms de dossiers. Garde en tête que ce récit vient surtout d'OpenAI. Le message à l'écran est résumé, pas cité. Suite dans la partie 2.
