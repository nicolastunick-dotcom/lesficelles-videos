# Ép. 18 — L'obsolescence programmée (manipulation de masse, 9/10)

**Description**
L'obsolescence programmée : un produit conçu pour durer moins longtemps qu'il pourrait. Exemple réel, selon l'historien Markus Krajewski : en 1924, un cartel fixe la durée des ampoules et met une amende à qui dépasse. Ton dernier appareil a lâché pile après la garantie ?

**Sources (commentaires épinglés, ≤ 150 caractères)**
- Sources 1/3 : M. Krajewski, « The Great Lightbulb Conspiracy », IEEE Spectrum, octobre 2014 (cartel Phœbus, 1924).
- Sources 2/3 : Code de la consommation, art. L441-2 : l'obsolescence programmée est un délit depuis la loi de 2015.
- Sources 3/3 : indice de durabilité (télés, lave-linge) : remplace l'indice de réparabilité depuis 2025.
